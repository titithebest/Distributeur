# Distributeur
C'était un petit exercice que l'on pouvait faire, dans le cadre de mes études. Il sert à montrer les fondamentaux de la programmation que j'arrive bien à métriser (au moment que le git est publié).
Bien sûr, mon niveau est beaucoup plus élevé. Ca sert surtout, pour qu'une personne qui me demande ce que je sais faire est un petit apperçu.

## 🚀 Description
Distributeur de boisson. On insére la monaie que l'on souhaite, puis ensuite on fait sont choix. Si on a trop de monnaie, alors il nous rendra la monaie

## ✏️ Modification
Aucunes modifications du code, à l'exception de l'allignement du code qui a était remis au propre.
